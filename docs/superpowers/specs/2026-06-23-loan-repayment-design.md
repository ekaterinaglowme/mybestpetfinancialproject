# PetBank: учёт выданных займов, возврат и дисконтная ставка от времени

Дата: 2026-06-23
Ветка: `feat/loan-repayment`

## Контекст

PetBank — учебный FastAPI-сервис приёма заявок. `POST /applications` синхронно
решает `approved`/`declined` по возрасту и стране и **ничего не сохраняет** —
состояние нигде не хранится.

Новая потребность: после выдачи (одобрения) займа нужно уметь спустя время
узнать, **вернул ли человек деньги** и **сколько он должен сейчас**. Сумма долга
зависит от прошедшего времени по **дискретной** ставке: чем дольше прошло — тем
**ниже** ставка к телу займа (так сформулирована задача; экономическая
необычность принята осознанно).

Это первая фича, которой нужна «память» о прошлых заявках.

## Цели

1. При одобрении заявки **с суммой** — фиксировать выданный займ
   (`loan_id`, `amount`, `issued_at`).
2. `GET /loans/{loan_id}` — показывать статус «отдал/не отдал» и текущий долг
   (с учётом прошедшего времени и ставки).
3. `POST /loans/{loan_id}/repay` — отмечать факт возврата, **замораживая** долг
   на момент возврата.
4. Дискретная ставка от возраста займа: дольше → меньше %.

## Вне объёма

- **Персистентность.** Хранилище — `dict` в памяти процесса. Данные теряются при
  рестарте/редеплое (в Docker контейнер пересоздаётся). SQLite/файл + volume —
  отдельная следующая задача.
- Аутентификация/авторизация (её нет во всём сервисе).
- Частичные и многократные платежи: возврат одноразовый и полный. Графики
  платежей, пени сверх модели ставки — не делаем.
- Контракт ответа `POST /applications` не меняется (тело прежнее).

## Модель и логика (новый модуль `loans.py`)

Чистая логика и хранилище выносятся в отдельный модуль, чтобы не пухнул
`server.py` и чтобы расчёты тестировались без HTTP.

- In-memory хранилище: `_loans: dict[str, Loan]`.
- `Loan` (dataclass):
  - `loan_id: str` — равен `application_id`;
  - `amount: float` — тело займа (принципал);
  - `issued_at: date` — дата выдачи;
  - `repaid_at: date | None` — дата возврата; `None` = ещё не вернул.
- Функции (чистые, время передаётся аргументом — для детерминируемых тестов):
  - `rate_for_age(days: int) -> float` — дискретная ставка (таблица ниже);
  - `amount_owed(amount: float, age_days: int) -> float`
    = `round(amount * (1 + rate_for_age(age_days)), 2)`;
  - `create_loan(loan_id, amount, issued_at) -> Loan`;
  - `get_loan(loan_id) -> Loan | None`;
  - `mark_repaid(loan_id, when: date) -> Loan` — бросает `KeyError`, если займа
    нет, и `AlreadyRepaid`, если уже возвращён;
  - `reset()` — очистка хранилища (для изоляции тестов).

### Ставка (дискретная, дольше → меньше)

| Возраст займа, дней | Ставка |
|---|---|
| 0–7   | 0.10 |
| 8–30  | 0.05 |
| > 30  | 0.02 |

- Границы включительны: `0..7 → 10%`, `8..30 → 5%`, `31+ → 2%`.
- `age_days = (as_of - issued_at).days`. Для активного займа `as_of = сегодня`;
  для возвращённого `as_of = repaid_at` (долг заморожен на дату возврата).

## Выдача — правка `server.py` (`POST /applications`)

- После `make_decision`: если `status == "approved"` **и** `payload.amount` задан
  (не `None`) и `> 0` → `loans.create_loan(application_id, payload.amount, date.today())`.
- Тело ответа `ApplicationDecision` **не меняется** — займ сохраняется как
  побочный эффект.
- Одобрено без суммы → займ не заводится (`GET /loans/{id}` вернёт 404).

## `GET /loans/{loan_id}` — статус и долг

- Нет такого займа → **404** (`{"detail": "Заём не найден"}`).
- **200**, модель `LoanStatus`:
  ```json
  {
    "loan_id": "…",
    "amount": 100000.0,
    "issued_at": "2026-06-23",
    "status": "не отдал",
    "days_elapsed": 12,
    "current_rate": 0.05,
    "amount_owed": 105000.0,
    "repaid_at": null
  }
  ```
- Если возвращён: `status = "отдал"`, `repaid_at` заполнен, а
  `days_elapsed`/`current_rate`/`amount_owed` посчитаны на дату возврата
  (заморожены, дальше не меняются).

## `POST /loans/{loan_id}/repay` — отметить возврат

- Нет займа → **404**.
- Уже возвращён → **409** (`{"detail": "Заём уже отдан"}`).
- Успех → **200**: ставим `repaid_at = date.today()`, возвращаем `LoanStatus`
  (теперь `status = "отдал"`, сумма заморожена).

## Тесты (TDD)

- `tests/test_loans.py` — юнит на чистую логику:
  - `rate_for_age`: границы `0, 7, 8, 30, 31` → `0.10, 0.10, 0.05, 0.05, 0.02`;
  - `amount_owed`: пример на каждый порог + округление до копеек;
  - `create_loan`/`get_loan`: happy + неизвестный id → `None`;
  - `mark_repaid`: happy; повторный → `AlreadyRepaid`; неизвестный id → `KeyError`;
  - fixture, вызывающая `loans.reset()` перед каждым тестом (изоляция).
- `tests/test_http.py` — добавить интеграционные:
  - approved **с** `amount` → `GET /loans/{id}` = 200, `status="не отдал"`,
    свежий займ (0 дней) → ставка 0.10, `amount_owed = amount*1.1`;
  - approved **без** `amount` → `GET /loans/{id}` = 404;
  - declined → займа нет (`GET` = 404);
  - `POST /repay` → 200, `status="отдал"`; повторный → 409; неизвестный id → 404;
  - проверка порогов ставки 8–30/>30 — на уровне юнитов (там время передаётся
    аргументом), т.к. через HTTP свежий займ всегда имеет возраст 0.
