# Ежедневная выгрузка статуса в PDF

«Форма» (вёрстка и стили) фиксирована — каждый день меняем только содержимое.

| Файл | Назначение |
|---|---|
| `petbank-status-template.html` | Шаблон-форма: стили, таблицы, разделы. Здесь обновляешь цифры/текст. |
| `build-pdf.sh` | Рендерит шаблон в PDF через headless Chrome (кириллица + CSS). |

## Как выгрузить

```bash
./docs/status/build-pdf.sh
# → ~/Desktop/PetBank-status-ГГГГ-ММ-ДД.pdf  (дата подставляется автоматически)
```

Источник правды по содержанию — [`docs/STATUS.md`](../STATUS.md). Перед выгрузкой
обнови цифры в шаблоне под актуальный код/метрики (или попроси Claude пересобрать
содержимое из `origin/main`).
