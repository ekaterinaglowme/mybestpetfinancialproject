## ⚠️ Сначала прочти это: твоя локальная папка отстала от `main`

На момент написания этой документации твоя рабочая папка переключена на ветку
`feat/deploy-docker-run` — это **старый снимок**. В `origin/main` с тех пор уже
влиты три большие фичи, которых в твоих локальных файлах нет:

| Что уже на `main`, но не в твоём локальном `server.py` | Где живёт |
|---|---|
| JSON-логирование (структурные логи в stdout) | `logging_setup.py` |
| Middleware логирования HTTP-запросов + `request_id` | `server.py` |
| Prometheus-метрики на `GET /metrics` | `metrics.py` |

**Чтобы подтянуть актуальный код** (сделай, когда будешь готова; сначала
сохрани/закоммить текущие локальные правки — у тебя изменён `CLAUDE.md` и есть
неотслеживаемый `docker-compose.yml`):

```bash
git stash            # спрятать локальные правки (или git commit)
git checkout main
git pull origin main
git stash pop        # вернуть правки, если прятала
```

Подробный разбор «что влито, что в работе» — в [STATUS.md](STATUS.md).

## 🗺️ Что это за проект

**PetBank** — учебный сервис приёма заявок («банк»). По HTTP принимает заявку с
персональными данными (ФИО, телефон, дата рождения, страна) и возвращает решение
**approved** / **declined** по двум правилам:

1. возраст заявителя — **от 18 до 35 лет включительно**;
2. страна заявителя — **не в стоп-листе** (по умолчанию запрещён «Китай»).

Это одно приложение на **FastAPI + Uvicorn**, упакованное в Docker и
автоматически деплоящееся на виртуалку через GitHub Actions.
